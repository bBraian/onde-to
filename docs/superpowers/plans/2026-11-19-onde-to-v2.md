# Onde Tô? v2 — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O que entra na v2:
- visual cartoon;
- avatar Alfinete personalizável;
- animações;
- modo "Neste PC" (1–8 jogadores, palpite em turnos ou no mesmo mapa, pontuação por
  distância ou por rodada);
- pontuação por rodada na sala online;
- troca para o Google Street View por configuração.

**Architecture:**
- `packages/shared` ganha o modelo do avatar, a regra `roundPoints` e os campos novos do
  protocolo.
- O servidor guarda o avatar e a pontuação por rodada.
- No site:
  - os tokens e o CSS são reescritos no estilo v2;
  - o desenho do avatar sai de um gerador de SVG (`pinSvg`), usado pelo componente e pelos
    marcadores do mapa;
  - o modo local é um reducer puro;
  - o visor de rua passa a ter um provedor plugável (Mapillary ou Google).
- O script de mapas ganha `--provider google`.

**Tech Stack:** além da v1:
- `motion ^14.14.0`, importado de `motion/react`;
- `canvas-confetti ^1.9.4` e `@types/canvas-confetti ^1.9.0`;
- `@googlemaps/js-api-loader ^2.1.3`, com `setOptions` e `importLibrary`;
- `@types/google.maps ^3.66.10`.

**Spec:** `docs/superpowers/specs/2026-11-19-onde-to-v2-design.md`, que complementa
`docs/superpowers/specs/2026-11-18-onde-to-design.md`. Mockups:
https://claude.ai/artifact/T1UWzK7YVCViaNjZL4dbjh, linha "v2".

## Global Constraints

- Todas as regras da v1 seguem valendo:
  - a interface é toda em pt-BR;
  - créditos: `© Mapillary` com link para a página inicial;
  - o tempo é controlado pelo servidor (horário absoluto);
  - a resposta fica escondida até `result`;
  - o `localStorage` fica dentro de `try/catch`.
- Todas as variáveis de ambiente do site são lidas só em `apps/web/src/lib/config.ts`. Um hook
  local bloqueia comandos de shell que contêm a sequência ponto + "env". Arquivos com essa

## Review Focus

1. **Turnos que vazam o palpite anterior.** Na vez seguinte, o mapa e a foto de quem joga não
   podem mostrar o pino do jogador anterior, e nada mostra palpite antes do "Revelar". O teste
   fica no Task 5 (o estado da vez seguinte não expõe palpites) e no Task 6 (E2E: o pino some
   na troca de vez).
2. **Tempo esgotado no modo local.**
   - Em Turnos: quem não chutou fica sem palpite e a vez passa.
   - Em Mesmo mapa: quem não marcou fica sem palpite e a rodada é revelada.
   - O teste fica no Task 5.
3. **Avatar malformado** (`localStorage` antigo ou cliente mexido). Vira o padrão, sem quebrar,
   no navegador e no servidor. O teste fica no Task 1 (`sanitizeAvatar`), no Task 2 (join com
   lixo) e no Task 3 (storage).
4. **"Reduzir movimento" ligado.** A contagem de pontos mostra o valor final na hora, não sai
   confete e os botões respondem sem atraso. O teste fica no Task 3 (`useCountUp`,
   `celebrate`).
5. **Google mal configurado:**
   - provedor `google` sem chave: o visor mostra "Falta configurar a chave do Google" (teste
     no Task 8);
   - servidor e site com provedores diferentes: a sala mostra o aviso da spec (teste no
     Task 7).

**Files:**
- Create: `apps/web/src/game/local.ts` (substitui `training.ts`, que é removido junto com o
  teste)
- Test: `apps/web/test/local.test.ts` (inclui o equivalente dos casos de `training.test.ts`)

**Interfaces:**
- Consumes: `scoreGuess`, `roundPoints`, `createDeck`, `GameMap`, `Movement`, `Scoring` e
  `Avatar`.
- Produces:
  ```ts
  type GuessMode = 'turns' | 'same-map';
  interface LocalPlayer { id: string; nick: string; avatar: Avatar }
  interface LocalSettings { mapId: string; rounds: number; timeSec: number | null; movement: Movement; guessMode: GuessMode; scoring: Scoring }
  interface LocalRoundResult { round: number; answer: MapPoint; guesses: { playerId: string; guess: LatLng | null; distanceKm: number | null; score: number; points: number }[] }
  type LocalState =
    | { phase: 'setup' }
    | { phase: 'gate'; …Playing; turnIndex: number }              // só em 'turns': "Vez de X"
    | { phase: 'guessing'; …Playing; turnIndex: number; activeId: string } // em 'turns' o activeId é quem joga; em 'same-map' é o chip selecionado
    | { phase: 'result'; …Playing; last: LocalRoundResult }
    | { phase: 'final'; players; settings; map; history: LocalRoundResult[]; totals: Record<string, number>; winners: string[] };
  // Playing = { settings; map; players; queue: MapPoint[]; round; point; order: string[]; deadline: number | null;
  //            pending: Record<string, LatLng | null>; totals: Record<string, number>; history: LocalRoundResult[] }
  type LocalAction =
    | { type: 'start'; settings: LocalSettings; players: LocalPlayer[]; map: GameMap; rng: () => number; now: number }
    | { type: 'ready'; now: number }                     // gate → guessing
    | { type: 'select'; playerId: string }               // same-map: muda o chip ativo
    | { type: 'place'; guess: LatLng }                   // same-map: põe/move o pino do ativo
    | { type: 'guess'; guess: LatLng | null; now: number } // turns: confirma a vez (null = tempo esgotado)
    | { type: 'reveal' }                                 // same-map: só quando todos marcaram
    | { type: 'timeout' }                                // same-map: revela com quem faltou = null
    | { type: 'next'; now: number }
    | { type: 'skip'; now: number }                      // foto quebrada: troca o ponto, zera pending, mantém a rodada
    | { type: 'setup' };
  function localReducer(s: LocalState, a: LocalAction): LocalState;
  function visiblePins(s: LocalState): { playerId: string; guess: LatLng }[]; // o que o mapa de palpite pode mostrar agora
  ```
- Regras:
  - `order` gira 1 posição a cada rodada.
  - Com 1 jogador, `guessMode` é tratado como `'turns'` sem a tela de vez: `start` vai direto
    para `guessing`.
  - Em `turns`, o `deadline` vale por vez e é recriado no `ready`.
  - Em `same-map`, o `deadline` vale por rodada.
  - O ponto da rodada é de `scoring`: `score` com `'distance'` e `points` (de `roundPoints`) com
    `'rounds'`.
  - `winners` são todos os jogadores com o maior total.

- [ ] **Step 1: Escrever os testes que falham.** Os nomes e as asserções-chave:
  - `turns: start vai para gate do primeiro da ordem; ready → guessing`
  - `turns: guess passa para o gate do próximo e visiblePins fica vazio` (Review Focus #1)
  - `turns: último guess → result com os palpites de todos`
